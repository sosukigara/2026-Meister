## 概要

ROS 2 (Jazzy) + Gazebo をベースとした**シミュレーション優先**の自律移動ロボット制御ソフトウェア。
SLAM による地図作成、Nav2 による自律ナビゲーション、Web UI による遠隔操作を提供する。
マイコン層（ファームウェア）は含まない。「モータ制御」は Gazebo プラグイン（シミュレーション時）または外部ハードウェアドライバ（実機時）に委譲される。

## システム構成

```
Meister/
├── start_meister.sh                 # メイン起動スクリプト
├── scripts/start_mapping_nav.sh     # 起動スクリプト（旧版）
└── src/
    ├── meistar_description/         # ロボットモデル・シミュレーション定義
    ├── ros2_autonomous_nav/         # SLAM・ナビゲーションの中核パッケージ
    └── meister_web_nav/             # Web UI（:8088）
```

※ `src/meister_robot/` と `src/rosnav/` は機能コードを含まない空の残骸ディレクトリのため仕様対象外。
※ `ros2_autonomous_nav` 内の動画編集・ナレーション生成スクリプト群（YouTube 用）はロボット制御と無関係のため仕様対象外。

3. **設計図** — モジュール構造・データフロー・状態遷移
