# 機能: 6輪ロッカーボギー・ステアリング・モータ制御

> 対象リポジトリ: `sosukigara/2026-Meister` | 作成日: 2026-08-12 | ステータス: 計画中

## 概要

実機の走行系。**6輪ロッカーボギーサスペンション**を備え、**全6輪独立ステアリング（シリアルサーボ）**と**6輪駆動（DC モータ・PWM）**を ESP32 が制御する。NASA ローバー方式で、超信地旋回・斜行・障害物乗り越えに対応する。

## 実装済み機能

- （未実装 — 計画中。現行のシミュレーションは差動2輪モデルのため、実機とは別物）

## 計画中機能

- [ ] 6輪ロッカーボギーサスペンション機構を組み立てる
- [ ] ステアリング: シリアルサーボ **6個**（全輪独立操舵）で各輪の向きを制御する
- [ ] 駆動: **DC モータ 6輪**（PWM 制御）で各輪を駆動する
- [ ] ESP32 でステアリングサーボと駆動モータを制御する
- [ ] PC(ROS 2) からの目標速度・目標舵角指令を受けて走行する

## 仕様化メモ

- **ステアリングサーボ**: 種類は要確定（Feetech STS3215 等のシリアルバスサーボ想定）。6個を UART バス1系統でデイジーチェーン接続できる。
- **駆動モータ**: DC ギヤードモータ想定。エンコーダ付きにすると速度制御・オドメトリ精度が上がる。
- **モータドライバ**: ESP32 の PWM 出力からモータドライバモジュール（例: TB6612 / DRV8833 / BTS7960 等）を介して駆動。
- **走行モード**: 全輪独立操舵により「前進・後進・斜行・超信地旋回」が可能。Nav2 の経路追従と整合させる。
- 電源容量（モータ6個 + サーボ6個 + アーム）の見積もりが必要。
