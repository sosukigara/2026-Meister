# M5Stack Tab5 IMU ファームウェア Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tab5 の BMI270 6軸を読み、USB シリアルで PC へ送り、Tab5 画面に表示するファームウェアを `firmware/m5stack_imu/` に追加する。

**Architecture:** フレームエンコード（`imu_protocol`）と固定小数点変換・姿勢計算（`imu_sampling`）は M5 依存を排除して native でテストする。M5 依存は `imu_view`（描画）と `main.cpp`（取得・送信）だけに閉じ込める（R8）。

**Tech Stack:** PlatformIO / ESP32-P4 (`m5stack-tab5-p4`) / Arduino / M5Unified >= 0.2.23 / M5GFX >= 0.2.30 / Unity native tests

**Spec:** `docs/superpowers/specs/2026-11-28-m5stack-imu-design.md`

## Global Constraints

- 設定値は `include/imu_config.h` の 1 箇所だけに定義する（R2）。
- 物理値の出典は `imu_config.h` のテーブルコメントに書く（R3）。未実測値は実測と書かない（R4）。
- `main_board/` のファイルは変更しない。
- フレームは `[A5][84][ts u32 LE][ax ay az gx gy gz int16 LE][status u8][xor]` の 20 バイト。XOR はフレーム全バイトが 0 になる方式。
- スケールは accel 1 G = 1000、gyro 1 deg/s = 100（プロトコル表現の選択）。
- 周期 20 Hz、シリアル 115200 baud。
- 実機は未接続。`★要確認★`（ポート名・表示・送信の実動作）として README に明記する。
- コミットは worktree `.worktrees/m5stack-imu` 内だけで行う（R13）。

## Review Focus

- フレーム長 20 バイトがずれると PC 側が永遠に同期しない → `test_encode_layout` が全バイト位置とサイズを固定する（Task 1）。
- `int16` の境界値と負値で符号が壊れると表示と PC 側の値が反転する → `test_decode_negative_values` / `test_convert_clamps_and_flags` が境界を固定する（Task 1/2）。
- IMU 未更新時に前回値を送ると「動いている」と誤判定される → `test_convert_missing_imu_sets_status` が kImuMissing を固定する（Task 2）。
- チェックサム不正フレームをデコーダが受けると PC 側が壊れた値を晒す → `test_reject_bad_checksum` が拒否を固定する（Task 1）。
- M5 依存コードが native テストに混ざるとビルドが落ちる → native env の `build_src_filter` で `main.cpp` / `imu_view.cpp` を除外し、Task 3 の `pio run` で両方の環境を確認する（Task 3）。

### Task 2: IMU 値変換と姿勢計算

**Files:**
- Create: `firmware/m5stack_imu/include/imu_sampling.h`
- Create: `firmware/m5stack_imu/src/imu_sampling.cpp`
- Test: `firmware/m5stack_imu/test/test_sampling/test_sampling.cpp`

**Interfaces:**
- Consumes: `protocol::Sample`, `protocol::StatusBits`（Task 1）
- Produces: `RawImu { float accel[3]; float gyro[3]; uint32_t timestamp_ms; bool present; }`, `ConvertSample(const RawImu&, protocol::Sample*) -> void`, `Attitude { float roll_deg; float pitch_deg; }`, `EstimateAttitude(const RawImu&) -> Attitude`.

- [ ] **Step 1: テストを書く**

`test/test_sampling/test_sampling.cpp` に次を書く: 公称値 `{0.5,-0.25,1.0}` G / `{10,-20,30}` dps が `{500,-250,1000}` / `{1000,-2000,3000}` に変換され status が 0、範囲外の値が `INT16_MAX` / `INT16_MIN` にクランプされ `kClamped` が立つ、`present=false` で `kImuMissing` が立ち値が 0 になる、`NaN` が 0 + `kClamped` になる、水平姿勢で roll/pitch が 0、X 軸 +1G で pitch が -90 度。

- [ ] **Step 2: 失敗を確認**

Run: `cd firmware/m5stack_imu && pio test -e native --filter test_sampling`
Expected: コンパイル失敗（ヘッダ未作成）。

- [ ] **Step 3: 実装**

`imu_sampling.h/.cpp` に ConvertSample と EstimateAttitude を実装する。スケールは `config::kAccelScale` / `config::kGyroScale` を使う。クランプは `isfinite` と `INT16_MIN/MAX` で行う。姿勢は `atan2(ay, az)` / `atan2(-ax, hypot(ay,az))` の度数変換（画面表示用の簡易値）。

- [ ] **Step 4: パスを確認**

Run: `cd firmware/m5stack_imu && pio test -e native`
Expected: test_protocol と test_sampling の両方が PASSED。

- [ ] **Step 5: コミット**

`git add firmware/m5stack_imu/include/imu_sampling.h firmware/m5stack_imu/src/imu_sampling.cpp firmware/m5stack_imu/test/test_sampling && git commit -m "feat(m5stack_imu): convert IMU readings to fixed-point samples"`
