# 機能: 自動制御（自動移動 → 完全自律）

> 対象リポジトリ: `sosukigara/2026-Meister` | 作成日: 2026-08-12 | ステータス: 計画中

## 概要

ロボット全体の自動化。**理想は完全自律**（人が介在しない運用）だが、実装順は**自動アーム → 自動移動 → 完全自律**の順で進める。
自動移動は既存の SLAM / Nav2 資産を実機（LD-D500 LiDAR 搭載）で動作させることで実現する。

## 計画中機能

- [ ] **自動移動**: 実機に搭載した 2D LiDAR（LD-D500）で SLAM 地図作成・自己位置推定を行い、Nav2 で自動走行する
- [ ] ウェイポイント巡回: Web UI で指定した複数地点を自動で巡回する
- [ ] **接近把持連携**: 把持対象がアーム可動域外の場合、台車を移動させて接近してから把持する（09-object-grasping の第2段階）
- [ ] **完全自律（理想）**: 自動巡回 + 障害物回避 + 物体把持・回収を統合し、人が介在しない運用を実現する

## ロードマップ（優先順位）

1. **自動アーム**（最優先）: 4軸アーム + 画像認識 + 自動把持（09-object-grasping）
2. **自動移動**: LD-D500 LiDAR + 既存 SLAM/Nav2 の実機移植 + ウェイポイント巡回（本ファイル）
3. **完全自律**（理想）: 上記すべてを統合

## 仕様化メモ

- **LiDAR**: LD-D500（2D LiDAR）。既存の `slam_toolbox` / Nav2 / `maps/` 資産がそのまま利用できる。
- **センサ統合**: オドメトリは 6輪のエンコーダ（搭載する場合）から算出。`/scan` と odom を既存の SLAM/Nav2 配管に接続する。
- **実機移植の要点**: `use_sim_time` の切り替え、トピック名・座標系（map/odom/base_link）の整合、ESP32 経由の cmd_vel 配線。
- 完全自律の実現には障害物回避の統合と、把持失敗時のリカバリ（再試行・次の対象へ）が必要。
