## G1: ロッカーボギーロボット自動走行

6輪ロッカーボギーの実機が、LD-D500 LiDAR と既存の SLAM / Nav2 資産を使って自動走行する。
[features/](features/) 01・02・03・04・07・08・10 と [functions/](functions/) を参照。

## G2: 自動でアームでものを回収

4軸アーム + 手首カメラの画像認識で物体を検出し、自動で掴んで回収する。
[features/09-object-grasping.md](features/09-object-grasping.md) を参照。

## G3: 手動操縦も可能

自動走行に加えて、手動（キーボード / ゲームパッド等）での操縦も可能にする。
シミュレーションでは teleop_twist_keyboard（04）が実装済み。実機では ESP32 経由の指令経路（07・08）で実現する。
