# 混入 blocklist の説明

`tools/corruption_blocklist.txt` は **1 行 1 トークンだけ**を書く。
説明文をこのファイルに書くと、その語が検査語になる（コメントを
スキップしない実装だと `の` などで全件が誤検出になる）。

## 入れるもの

「この文字列が日本語文中に現れたら確実に汚染」な **CJK 混在トークン**のみ。
実際に混入した事例から増やす。

## 入れないもの

- **1 漢字のトークン**（`な` `学` `壊` など）— 日本語の超高頻度語
- **英語単語**（`dispute` `learned` `models` など）— `src/meister_vision/models/`
  のような実在パスにマッチする
- **日本語の通常語**（`壊れ` `全体` の通常用法など）— 誤検出になる

誤検出放入の検査器は `residual=0` が「clean」の意味を失う。

## 検査の限界

1 漢字だけの混入（`運動学` の `学`）は、**漢字が日本語と簡体字で共有して
いるため検出が原理的に不可能**。差分の目視が必須。

検査本体は `tools/check_text.py`。
